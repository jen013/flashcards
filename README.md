# Flashcards

Flashcards is a simple website meant to help users study through self-quizzing. Users can create, edit, delete, and study/play their own flashcard sets right away. Each flashcard has two sides that can hold information, (e.g., a question and an answer). Playing a flashcard set lets users practice and test their memorization of the information.

## Features

- Creation, modification, and deletion of flashcard sets, which each contain a title and doubled-sided cards that can hold text.

- Ability to play a flashcard set which includes the following:
  - Automatically hidden card side, which can be revealed and re-hidden by the user.
  - Card sequence options, which include shuffling/randomization and an infinite mode for continuous studying.
  - Card view options, which include choice of what card side is displayed first, and toggle for a side-by-side or single-sided view of the flashcard.

## Future Development

- **More Media:** Allow users to add images and audio into their flashcards.
- **More Study Customization:** Allow users to disable cards before studying a flashcard set.
